# Mindustry Cheatsheet

A compact visual reference for Erekir and Serpulo infrastructure, defence, and unit progression.

## Open the cheatsheet

[Open Mindustry Cheatsheet in your browser](https://html-preview.github.io/?url=https%3A%2F%2Fgithub.com%2Fiamchoking%2Fmindustry_cheatsheet%2Fblob%2Fmain%2Findex.html)

Use the planet menu in the top-right to switch between Erekir and Serpulo; Erekir is selected by default. Use the tabs to switch sections, choose the latest captured sector to hide unavailable blocks, and hover over entries for official descriptions. The **Download** button saves the current view as a PNG.

The Serpulo reference data and sprites are based on the official Mindustry v157.4 content definitions.

## Run locally

You can open `index.html` directly, or serve the folder locally:

```sh
python3 -m http.server 8000
```

Then open <http://localhost:8000>.
